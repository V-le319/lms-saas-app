# AI Learning Companion

An AI-powered Learning Management System (LMS) and voice tutoring web application built by following JSMastery tutorial. It allows users to create custom AI companions, engage in real-time voice conversations with AI tutors, and track their learning progress.

🌐 **Live Demo:** [lms-saas-app-omega.vercel.app](https://lms-saas-app-omega.vercel.app)

---

## ✨ Features

- **Custom AI Companions:** Configure and create personalized AI tutors targeting specific topics, subjects, and conversational styles.
- **Real-Time Voice Tutoring:** Interactive spoken tutoring sessions driven by Vapi and ElevenLabs integrations.
- **Session & Journey Tracking:** Monitor completed lessons, track created companions, and review personal learning metrics.
- **Subject Filtering:** Filter learning companions dynamically using color-coded category tags.
- **Authentication:** Secure user onboarding and session handling powered by Clerk.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI 
- **Auth:** Clerk
- **Database:** Supabase
- **AI & Voice:** Vapi AI
- **Deployment:** Vercel
